## Quick Start

```bash
# 1. Clone/download to your computer
cd ai-compare-hub

# 2. Install Hugo (if not installed)
# macOS: brew install hugo
# Ubuntu: sudo apt install hugo
# Windows: choco install hugo.extended

# 3. Preview locally
hugo server

# 4. Build for production
hugo --minify

# 5. Deploy public/ folder to GitHub Pages
```

## Deployment Checklist

- [ ] Create GitHub repo: `ai-compare-hub`
- [ ] Push all files to repo
- [ ] Go to Settings → Pages → Source: GitHub Actions

- [ ] Change `baseURL` in `_config.toml` to your actual URL
- [ ] Rebuild: `hugo --minify --gc`
